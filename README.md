# Java Object-Oriented Programming (OOP) Practice

A collection of Java programs developed for practicing fundamental Object-Oriented Programming (OOP) concepts, including inheritance, encapsulation, method overloading, method overriding, and runtime polymorphism.

## 📂 Repository Contents

| # | File Name | Concept Demonstrated | Description |
|---|---|---|---|
| 1 | `ShapeRectangle.java` | Method Overloading & Overriding | Demonstrates square and rectangle area calculations using overloaded methods and inheritance. |
| 2 | `UniversityManagement.java` | Inheritance | Demonstrates inheritance using university students and teachers. |
| 3 | `EmployeeManager.java` | Inheritance & Method Overriding | Demonstrates Employee and Manager classes using `super()` and method overriding. |
| 4 | `BankingSystem.java` | Inheritance & Method Overriding | Demonstrates SavingsAccount and CurrentAccount using overridden display methods. |
| 5 | `PaymentSystem.java` | Runtime Polymorphism | Demonstrates Cash, Card, and Online payment methods using a parent-class reference. |
| 6 | `BankEncapsulation.java` | Encapsulation | Demonstrates data protection and validation using private data members. |

---

## 🛠️ Setup & Execution

### Prerequisites

- Java Development Kit (JDK 17 or later recommended).
- Any Java-compatible code editor or terminal.

### Running a Program

Compile a Java file:

```bash
javac ShapeRectangle.java
```

Run the compiled program:

```bash
java ShapeRectangle
```

Replace `ShapeRectangle` with the name of the class you want to execute.
