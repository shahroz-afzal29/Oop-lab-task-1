# Java Object-Oriented Programming (OOP) Practice

A collection of 12 foundational Java programs demonstrating essential Object-Oriented Programming concepts, method overloading, inheritance, polymorphism, composition, encapsulation, and user input.

## 📂 Repository Contents

| # | File Name | Concept Demonstrated | Description |
|---|---|---|---|
| 1 | `UserGreeting.java` | Standard I/O | Takes user name and displays a greeting. |
| 2 | `AreaOverloading.java` | Method Overloading | Calculates areas of square, rectangle, and circle using overloaded methods. |
| 3 | `ShapePolymorphism.java` | Runtime Polymorphism | Demonstrates method overriding using Shape, Circle, and Rectangle. |
| 4 | `AnimalPolymorphism.java` | Runtime Polymorphism | Demonstrates method overriding using Animal, Dog, and Cat. |
| 5 | `EmployeePostComposition.java` | Composition (Has-A) | Demonstrates the relationship between Employee and Post classes. |
| 6 | `UniversityManagement.java` | Inheritance | Demonstrates inheritance using university students and teachers. |
| 7 | `BankEncapsulation.java` | Encapsulation | Demonstrates bank account data management and validation. |
| 8 | `CarEngineProgram.java` | Composition (Has-A) | Demonstrates the relationship between a Car and its Engine. |
| 9 | `CarTypeProgram.java` | Inheritance | Demonstrates different car types using parent and child classes. |
| 10 | `RestaurantBilling.java` | Method Overloading | Calculates restaurant bills using price, quantity, discount, and 10% tax. |
| 11 | `StudentIncrement.java` | Constructors & Static Variables | Checks duplicate student IDs and increments the student count for new students. |
| 12 | `Salary.java` | Inheritance & Method Overriding | Calculates salary increments for permanent and contract employees using `super`. |

## 🛠️ Setup & Execution

### Prerequisites

- Java Development Kit (JDK 17 or later recommended).
- Any Java-compatible code editor or terminal.

### Running a Program

To compile and execute a Java program:

**Compile:**
```bash
javac AnimalPolymorphism.java
```

**Run:**
```bash
java AnimalPolymorphism
```

Replace `AnimalPolymorphism` with the name of the class you want to execute.

## 🎯 Learning Objectives

- Understand Java classes and objects.
- Practice constructors and constructor overloading.
- Understand inheritance and the `super` keyword.
- Implement method overloading and method overriding.
- Learn runtime polymorphism.
- Understand composition and Has-A relationships.
- Practice encapsulation and data validation.
- Work with user input using `Scanner`.
- Apply basic conditional statements and calculations.
